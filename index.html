GUIDE

使い方

画像を読み込む

  • ドラッグ＆ドロップ、ファイル選択、Ctrl / ⌘ + Vで読み込めます
  • 画像はこのブラウザ内だけで処理され、外部へ送信されません

基本の流れ

  1. 必要に応じて範囲を選択します
  2. 左側で透過・色置換・塗りつぶし・ぼかしを設定して適用します
  3. 右側でファイル名と出力サイズを設定し、ダウンロードまたはコピーします

選択とトリミング

  • 選択なしでは画像全体、選択ありでは選択範囲だけに加工を適用します
  • 矩形選択・投げ縄・自動選択を使用できます。Ctrl / ⌘を押しながら操作すると範囲を追加できます
  • 選択範囲は反転・解除でき、1〜20pxの拡張・縮小・境界ぼかしができます
  • トリミングと矩形選択では、キャンバス左上の「自由」「カスタム」「1:1」「4:3」「3:2」「16:9」で縦横比を指定できます。「カスタム」を選ぶと横・縦の入力欄が表示され、入力した比率がすぐに反映されます。「自由」以外では横長長方形・縦長長方形のアイコンで向きを切り替えられます。初期状態は横長です。Shiftを押しながらドラッグすると一時的に正方形になります
  • 確定・反転・選択解除などのキャンバス操作は左上に表示され、比率コントロールがある場合はその右側に並びます
  • トリミングは範囲をドラッグし、「確定」またはEnterで実行します
  • トリミング時だけ表示される「透明余白削除」で、透明になった外周を自動的に切り詰めます

キャンバス表示

  • マウスホイールで拡大・縮小します
  • 右クリックしながらドラッグすると、どのモードでも画像を移動できます
  • フィットボタンで画像全体を表示領域に合わせます

ぼかし

  • ガウス：画像を滑らかにぼかします
  • モザイク：画像をブロック状にぼかします
  • 強度やサイズを上げるほど効果が強くなります

履歴・リセット・出力

  • 右側の履歴をクリックすると、その時点の状態へ戻れます
  • Ctrl / ⌘ + Zで元に戻し、Ctrl / ⌘ + Shift + ZまたはCtrl + Yでやり直します
  • リセットは読み込み時の状態へ戻し、クリアは編集中の画像を閉じます
  • ダウンロードはPNG保存、コピーはPNG画像をクリップボードへコピーします。選択表示は出力画像に含まれません
